
# Actividad final: desarrollo de una Pokédex con JavaScript

En esta actividad ampliarémos la mini-Pokédex desarrollada en la guía de la práctica Pre-pokédex hasta convertirla en una Pokédex más completa. La aplicación consultará información real de Pokémon mediante PokéAPI y generará su contenido dinámicamente con JavaScript.

---

## 1. Punto de partida:

Primeramente hemos desarrolado una mini-pokédex, en la cuál se encontrará la base de la que vamos a realizar en un futuro con una versión mejorada. Ests mini-pokédex, tiene de momento:
- Una barra de búsqueda en la cual puedes añadir el número o el nombre del pokémon a buscar.
- Cuando se busca nos aparece el número en la pokédex del pokémon, el nombre, su peso y estatura, además de su tipo.
- Dicha pokédex se conecta a una api la cual tiene todos los pokémon más su información.
